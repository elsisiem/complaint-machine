How it works

Drafts

Llama 3.3 70B on Novita AI writes the complaint letter, the text for each filing venue, tweet drafts and follow-ups. Review and edit all of it. Fill in the [YOUR ...] placeholders.

Contact suggestions

The model guesses company contacts and can be wrong. Each one is an unverified suggestion. Check it on the company's official website before you use it.

Sending

You can email one recipient and post one tweet through ActionLayer. Each time, the app shows the exact recipient and text and waits for you to approve. The server rejects any send that is not marked confirmed.

File it yourself

For the BBB, the CFPB (financial issues), your state attorney general and the FTC, the app drafts the text and links to the official page. You submit it.
